---\n### Aufgabenbeschreibung:\nImplementiere die folgenden Funktionalitäten für Tasks:\n\n1. **Optionales Due Date (Zieldatum):**\n   - Aufgaben können ein Zieldatum (`dueDate`) enthalten, dies soll aber nicht verpflichtend sein.\n   - Der Aufgabenstatus `isUrgent` wird automatisch auf `true` gesetzt, wenn das aktuelle Datum nahe am Zieldatum liegt (z. B. ≤ 3 Tage).\n\n2. **Smarte Regeln:**\n   - Implementiere ein Regelwerk, das flexibel und erweiterbar ist.\n   - Beispielregel: Setzen des Status "eilig" kurz vor dem Erreichen des entsprechenden Zieldatums.\n   - Ermögliche die Deaktivierung dieser Regeln pro Benutzer unter einem neuen Bereich "Personalisieren".\n\n3. **Transparenz:**\n   - Dokumentiere die smarten Regeln im Code und mache sie für Nutzer nachvollziehbar.\n\n### Vorschlag zur Umsetzung:\n- Backend-Modell anpassen:\n   - `dueDate` als optionales Feld in das Task-Modell integrieren.\n   - `isUrgent` dynamisch je nach Näherung an das `dueDate` setzen.\n\n- **Smarte Regeln:**\n   - Erstelle eine flexible Regel-Engine, die leicht erweiterbar ist.\n\n- Frontend:\n   - UI-Element für die Eingabe von optionalem `dueDate`.\n   - Bereich "Personalisieren" für die Aktivierung oder Deaktivierung von smarten Regeln.\n\n- Tests:\n   - Füge Unit- und Integrationstests für Backend und Frontend hinzu.\n\n### Erweiterungsmöglichkeiten:\n- Benachrichtigungssystem für "eilige" Tasks.\n- Unterschiedliche Schwellenwerte pro Benutzer oder Task-Typ.
